# Rusça Defterim

Kişisel Rusça öğrenme defteri: metin, ekran görüntüsü (OCR) ve videodan kelime/cümle/kalıp toplama, Rusça seslendirme, flash kartlar ve eşleştirme oyunları.

- Tek sayfalık web uygulaması (`index.html`), kurulum gerektirmez.
- Telefonda Safari → Paylaş → **Ana Ekrana Ekle** ile uygulama gibi kullanılır.
- Kişisel veriler bu depoda **tutulmaz**; tarayıcıda (ve ileride kullanıcının kendi Google Drive'ında) saklanır.
